# 臺灣 ETF 風險與報酬實證分析

本專案比較五檔臺灣上市股票型 ETF 在 2021–2025 年間的歷史報酬與風險，
探討「較高的已實現歷史報酬，是否必然伴隨較高的歷史風險」。

## 研究標的

- 0050 元大台灣50
- 0056 元大高股息
- 00692 富邦公司治理
- 00713 元大台灣高息低波
- 00878 國泰永續高股息

## 研究方法

資料來源為 Yahoo Finance 的調整後收盤價，使用 Python 計算：

- 累積報酬率
- 年化報酬率
- 年化波動率
- 最大回撤

## 主要結果

| ETF | 累積報酬率 | 年化報酬率 | 年化波動率 | 最大回撤 |
|---|---:|---:|---:|---:|
| 0050 | 144.95% | 19.67% | 21.28% | -33.83% |
| 0056 | 84.88% | 13.11% | 15.70% | -26.89% |
| 00692 | 136.98% | 18.88% | 19.29% | -30.87% |
| 00713 | 111.38% | 16.19% | 12.81% | -18.42% |
| 00878 | 91.45% | 13.91% | 14.39% | -22.29% |

在本研究的樣本、期間與風險定義下，較高的歷史報酬不必然伴隨較高風險。
此結果不能推論至所有 ETF、其他期間或未來報酬。
